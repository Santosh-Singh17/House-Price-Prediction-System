# 🏠House Price Prediction System

## Project Description

The House Price Prediction System is a Machine Learning project that predicts house prices based on user inputs using a trained ML model. The project also includes a Streamlit web application for an interactive user experience.

## Objective

* Predict house prices accurately.
* Provide an easy-to-use web interface.
* Demonstrate the application of Machine Learning in real-world scenarios.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Joblib

## How to Run Locally

1. Install the required libraries:

```
pip install -r requirements.txt
```

2. Run the application:

```
streamlit run app.py
```
